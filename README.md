# Auto-ARKit-UE-Shapekeys-
Vibecoded script that automatically adds empty Shapekeys to a mesh in Blender. 

## What it does?
* Creates empty shapekeys with either the ARKit or Unified Expressions naming scheme
* It also creates separation Shapekeys to keep it organized ("---Face Tracking---" and "---Blended Shapes---" (UE Only))

## Extra features
It can duplicate the blendshapes to translate them to ARKit or UE depending on your needs

You probably shouldn't use it as it increases VRAM usage, you should instead translate them via VRM Blendshape or within the software you wanna use
